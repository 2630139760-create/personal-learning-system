# 个人学习系统

一个离线优先、可逐步扩展的个人学习系统。目前包含“今日计划”、“账本”和“日记”。

## 本地预览

```bash
npm run dev
```

打开 <http://localhost:4173>。数据保存在当前浏览器的 IndexedDB 中；无需账号或付费服务。

## 检查

```bash
npm test
```

## 当前范围

- 北京时间的每日计划、历史日期与固定模板
- 任务增删改、时间冲突提示、学习/生活统计分离
- 单任务持久计时、分段记录、暂停恢复和时长修正
- JSON 导出与“合并 / 替换”恢复
- 账本：真实收支、日 / 周 / 月 / 年 / 自定义账单和分类管理
- 每月独立的 600 元日常预算、400 / 600 元提醒，分类与预算开关独立
- 五个小荷包资金项目：手动存入、月目标、跨月可用金额及关联支出扣减；不接入支付宝
- 账本金额以整数分保存于现有 IndexedDB 的 meta 中；备份包含账本，旧备份缺少账本字段时保留本机账本。恢复使用原子事务，失败不会留下半恢复数据
- 日记：北京时间、周一开始的月历，每日一篇；九种可取消选择的 SVG 心情，自由正文、可空的 Yes / Or / No 评估及 0—100 整数评分
- 日记按日期自动保存草稿，点击“保存日记”更新正式记录、日历及收藏；评分 0 与未评分、Or 与未选择分开保存。切换日期或模块前等待草稿落盘，刷新或重新打开后选择相应日期恢复草稿；保存失败保留输入并支持重试
- 收藏与搜索引用原记录，正文关键词及包含首尾的日期筛选可在日历和收藏夹使用；删除确认后同时移除正式日记、草稿和收藏
- 日记及草稿存于现有 IndexedDB 的 meta，同步纳入 JSON 导出、合并和替换恢复；旧备份缺少日记字段时保留本机日记。同日期的本机正式记录和草稿作为一组优先保留，备份中新日期正常导入
- 日记正文只保存于用户浏览器数据及用户主动导出的备份，不发送至服务端；预览与原网站不同来源的浏览器数据彼此独立
- 提醒设置仅保存配置；设备通知、跨设备同步、英语阅读器及其他业务模块后续接入
