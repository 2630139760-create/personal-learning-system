# 个人学习系统

一个离线优先、可逐步扩展的个人学习系统。第一阶段实现 iPad 可用的“今日计划”。

## 本地预览

```bash
npm run dev
```

打开 <http://localhost:4173>。数据保存在当前浏览器的 IndexedDB 中；无需账号或付费服务。

## 检查

```bash
npm test
```

## 当前范围

- 北京时间的每日计划、历史日期与固定模板
- 任务增删改、时间冲突提示、学习/生活统计分离
- 单任务持久计时、分段记录、暂停恢复和时长修正
- JSON 导出与“合并 / 替换”恢复
- 提醒设置仅保存配置；设备通知、跨设备同步、英语阅读器及其他业务模块后续接入
